# Lumasela Shopify theme

An editable Shopify Online Store 2.0 theme for Lumasela's clear phone case and signature customization concept. It is built on Shopify's Dawn 16.0.0 foundation and keeps the Dawn license in `LICENSE.md`.

## Included storefront work

- English homepage with responsive product, lifestyle, gift, signature-style, customizer, detail and brand-story sections.
- Editable collection template with native Shopify filtering, sorting and product data.
- Dawn's production product template plus optional `product.lumasela` template for a verified phone-case product.
- Signature name, style, color and position are separate HTML controls. When the Lumasela product template is connected to a real product, the values are submitted as cart line-item properties.
- All marketing copy is editable in the theme editor. The included editorial images contain no marketing headlines, prices or buttons.

## Important status

- The included iPhone 18 Pro imagery is a **concept design**, not a claim of official Apple hardware or production-verified case fit.
- No material, drop-test, anti-yellowing, magnetic, manufacturing-time, delivery or warranty claims are asserted.
- The connected Shopify store currently contains TUMZARO lock-picking products, not Lumasela phone-case products. This theme does not modify that catalog.
- The homepage customizer therefore starts in clearly labelled design-preview mode. Connect a verified phone-case product in the theme editor before using it for orders.
- Do not publish the preview theme without the store owner's explicit approval.
